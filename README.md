# TaskFlow 📋

A full-stack task and project management application built for organizing projects, managing tasks, tracking progress, collaborating through comments, and managing user preferences from a modern dashboard.

## Project Overview

TaskFlow is a modern project and task management web application designed to help users organize their work efficiently.

Users can register, log in, create and manage projects, create and manage tasks, update task status, add comments, edit comments, manage their profile, and customize application preferences.

The application also provides a dashboard where users can quickly view their projects, tasks, and overall workspace activity.
